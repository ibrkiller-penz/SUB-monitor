PowerShell에 붙여 넣으면 바탕화면 SUBmonitor 폴더에 받아서 바로 실행합니다. 이미 쓰던 폴더라면 프로그램 파일만 바꾸고, 설정 파일 config.local.json은 그대로 남습니다. 압축은 진행 표시줄 없이 .NET으로 풀어 PowerShell 5에서 창이 꺼지는 문제를 피합니다.

$ProgressPreference = 'SilentlyContinue'
Stop-Process -Name SUBmonitor -ErrorAction SilentlyContinue
Start-Sleep 1
$D="$env:USERPROFILE\Desktop"; $z="$env:TEMP\SUBmonitor-win.zip"; $t="$env:TEMP\SUBmon_new"
Invoke-WebRequest "https://github.com/ibrkiller-penz/SUB-monitor/releases/download/latest/SUBmonitor-win.zip" -OutFile $z
Remove-Item $t -Recurse -Force -ErrorAction SilentlyContinue
Add-Type -AssemblyName System.IO.Compression.FileSystem
[IO.Compression.ZipFile]::ExtractToDirectory($z, $t)
Remove-Item "$D\SUBmonitor\_internal" -Recurse -Force -ErrorAction SilentlyContinue
Copy-Item "$t\SUBmonitor\*" "$D\SUBmonitor" -Recurse -Force
Start-Process "$D\SUBmonitor\SUBmonitor.exe"

03투입된 기술

고정 무대 + 자동 축소 CSS transform · @container

화면 전체를 1920×440 크기의 고정된 무대(#stage) 하나로 그리고, 창 크기에 맞춰 transform: scale()로 줄이거나 늘립니다. Windows 배율(125%·150%)이나 일반 창에서도 모양이 똑같습니다. 세로 모드는 440×1920 무대로 바꿉니다. 패널 폭이 좁아지면 @container 쿼리로 글자와 항목을 줄이고, 그래도 넘치면 스크립트가 글자를 한 단계씩 줄입니다.

주의: 컨테이너 쿼리 규칙은 스타일시트 맨 끝에 둬야 기본 규칙을 덮어씁니다.

시간표: 사이트의 계산 결과만 가져오기 WebView2 · JS 주입 · 파일 캐시

시간표 사이트는 화면을 그리기 전에 브라우저 안에서 대강·시험·행사를 계산합니다. 그래서 HTML을 긁지 않고, 사이트를 실제로 열어 그 계산 엔진(TimetableEngine)을 호출하는 JS를 주입해 데이터만 받습니다. 색과 디자인은 가져오지 않습니다.

  • 같은 프로세스의 숨은 창은 WebView2에서 로드되지 않고 화면 전체가 "응답 없음"이 됐습니다. 그래서 별도 프로세스로 분리했습니다.
  • 작업표시줄에 창이 계속 떠 있는 게 불편하다는 의견에 따라, 전 주차를 한 번에 긁어 tt_cache/<교사>.json에 저장하고 창을 바로 닫게 바꿨습니다.
  • 교사별로 캐시가 따로 있어 교사를 바꿨다 돌아와도 바로 뜹니다. 교장·교감은 시간표 없이 목록에만 넣었습니다.
  • 교체·보강·결강: 사이트는 기본 시간표를 먼저 그리고 변경 내역을 약 3초 뒤 서버에서 받습니다. 처음엔 화면이 그려지자마자 읽어 변경이 하나도 반영되지 않았습니다. 지금은 변경 내역 개수가 두 번 연속 같을 때까지(최대 20초) 기다렸다가 읽고, 맞교환은 "맞교환(상대 교사)", 옮겨 간 수업은 "수업 이동 ➔ 요일N교시"로 보여 줍니다.
  • 학평·정기고사: 시험일엔 사이트의 감독표(ExamProctor)에서 교시·시간·감독 반을 받아, 평소 시간표 대신 시험 시간표(8교시·한국사 포함)로 그리고 감독 교시를 강조합니다. 시계 아래 칩은 "지금/다음 감독"을 알려 줍니다.
  • 일과 후엔 내일: 오후 4시 40분(시험일엔 마지막 시험 끝)이 지나면 다음 날(금요일이면 다음 주 월요일) 시간표와 "내일 첫 수업"을 보여 줍니다.
  • 변환 규칙을 바꾸면 캐시 버전 번호를 올려, 업데이트 후 처음 켤 때 바로 다시 받게 했습니다.

쿨메신저 안읽은 쪽지 SQLite 읽기 전용 · base64 + zlib + UTF-16LE

쿨메신저는 공개 API가 없지만 받은 쪽지를 %LOCALAPPDATA%\CoolMessenger\Memo\<로그인명>.udb라는 SQLite 파일에 저장합니다. 이 파일을 읽기 전용으로 열어 tbl_recv에서 IsUnRead = 1인 쪽지만 보여 줍니다. 쿨메신저가 켜져 있어도 읽힙니다.

SELECT Sender, Title, MessageText, ReceiveDate, IsUnRead
FROM tbl_recv
WHERE (DeletedDate IS NULL OR DeletedDate = '') AND IsUnRead = 1
ORDER BY ReceiveDate DESC LIMIT 20;
  • 파일 이름은 Windows 계정이 아니라 쿨메신저 로그인 이름이라 *.udb 중 가장 최근 파일을 고릅니다.
  • 컬럼 이름이 IsUnRead라서 1이 "안읽음"입니다. 처음에는 반대로 해석해 배지가 틀렸습니다.
  • HTML 본문 MessageBody는 {COMP} 뒤에 base64 → zlib → UTF-16LE로 압축돼 있지만, 평문 MessageText가 있어 그걸 씁니다.
  • 화면에는 발신자와 내용만 보여 줍니다. MessageText는 보통 제목으로 시작해서, 앞의 제목 부분은 떼어 냅니다.
  • DB에는 절대 쓰지 않습니다. 패널의 지우기는 화면에서만 숨깁니다.
  • 패널을 누르면 쪽지만 크게 보여 주는 상세 화면: 보낸 사람·시간 한 줄 + 본문 최대 3줄.

학교 일정 웹앱 연동 Apps Script 페이지 파싱

Apps Script 웹앱은 실제 페이지를 샌드박스 iframe 속에 역슬래시-x로 이스케이프해 넣어 보냅니다. 이스케이프를 몇 번 풀어 <script id="init-data"> 안의 JSON을 꺼내면 부서 일정과 학사일정이 그대로 들어 있습니다. 10분마다 다시 받고, 설정의 새로고침을 누르면 즉시 받습니다.

화면 보호 용 Kling AI 영상 · ffmpeg 편집 · VP9 알파 webm

클링(Kling)에서 초록 배경의 황금용 영상을 만들고, ffmpeg로 편집해 배경이 투명한 webm을 프로그램에 넣었습니다.

  1. 10초 원본에서 용이 왼쪽을 보는 구간(8~10초, 0~1.1초)만 골라 이어 붙임
  2. 1.25배속, 앞으로 재생 후 거꾸로 재생해 끊김 없이 반복
  3. 초록이 다른 색보다 튀는 만큼 투명하게(크로마키), 가장자리 초록 번짐은 빨강 값으로 낮춤
  4. 화면에서는 오른쪽→왼쪽으로 물결치듯 이동, 진행 방향에 따라 머리를 들고 숙이게 기울임, 금빛 후광과 금가루 입자
ffmpeg -i kling.mp4 -an -filter_complex \
 "[0:v]trim=8:10.04,setpts=PTS-STARTPTS[a];[0:v]trim=0:1.1,setpts=PTS-STARTPTS[b];\
  [a][b]concat=n=2:v=1,setpts=PTS/1.25,scale=-2:460,format=rgba,\
  geq=r='r(X,Y)':g='min(g(X,Y),r(X,Y))':b='b(X,Y)':\
  a='255-clip((g(X,Y)-max(r(X,Y),b(X,Y))-14)*8,0,255)',format=yuva420p" \
 -c:v libvpx-vp9 -pix_fmt yuva420p -b:v 1800k dragon.webm

용 몸이 초록·청록이면 몸까지 지워집니다. 클링 프롬프트에 "용에는 초록 없음, 금·샴페인·아이보리만"을 넣는 게 핵심입니다.

바로가기 아이콘 띠 공식 아이콘 내장 · os.startfile · shell:AppsFolder

화면 오른쪽 끝에 폭 40px의 가는 띠를 두고 자주 쓰는 프로그램 6개(쿨메신저·카카오톡·Claude·한글·엑셀·파워포인트)를 세로로 넣었습니다. 누르면 바로 실행됩니다. 메뉴는 시계를 빼고 최대 5개까지 켤 수 있고, 바로가기는 폭이 좁아 개수에 넣지 않습니다(5개 + 바로가기).

  • 아이콘: 각 프로그램의 공식 아이콘을 128px PNG로 만들어 프로그램 안(web/apps/)에 넣음. PC마다 아이콘을 뽑을 필요가 없어 처음부터 바로 보임
  • 실행 경로: 먼저 알고 있는 설치 경로(Office16, HOffice130 같은 버전 폴더는 *로)를 보고, 없으면 시작 메뉴·바탕화면 바로가기 → 레지스트리(App Paths·설치 목록) → 스토어 앱 → Program Files 순서로 찾음. PowerShell 한 번, 창 없이 실행
  • 스토어 앱(Claude): WindowsApps 폴더는 버전이 바뀔 때마다 이름이 바뀌고 직접 실행이 막혀 있어서 explorer.exe shell:AppsFolder\<앱 ID>로 실행
  • 목록은 config.json > launchers에서 바꿀 수 있음

처음에는 PC에서 아이콘을 뽑아 썼는데, 공식 아이콘 이미지를 프로그램에 넣는 쪽이 더 깔끔하고 확실했습니다. 업데이트 zip은 SUBmonitor 폴더째 묶어야 압축을 풀었을 때 예전 exe를 실행하는 실수가 없습니다.

기상청·에어코리아 날씨 공공데이터포털 인증키 1개 · 격자 변환 · WMO 코드 맞춤

  • 초단기실황(매시 정각 관측): 지금 기온·습도·바람·강수형태. 초단기예보: 하늘상태·낙뢰
  • 단기예보(하루 8번 발표): 3일치 시간별 기온·강수확률·하늘, 최저·최고

  • 에어코리아: 가장 가까운 측정소의 실시간 PM10·PM2.5(점검 중이면 직전 시간 값)
  • 위경도 → 기상청 격자(nx, ny)는 람베르트 정각원추 변환식, 기상청 강수형태·하늘상태는 WMO 날씨 코드로 바꿔 넣음
  • 12시간 비 알림: 앞 12시간 중 비 예보이거나 강수확률 60% 이상인 첫 시각을 "15시부터 비 70%"로 크게. 비가 오고 있으면 "18시쯤 그침". 시간별 칸은 2시간씩 묶어 그사이 비도 놓치지 않게

3D 프린터 모니터 뱀부랩 MQTT · 비공식 계정 API · 전체 화면 알림

뱀부랩 프린터는 MQTT로 출력 상태(진행률·남은 시간·층·온도·단계)를 보냅니다. 연결 방법은 두 가지를 넣었습니다.

  • 같은 네트워크 직접: 프린터 IP·액세스 코드·시리얼로 접속. 카메라(RTSPS)도 ffmpeg로 초당 2장 받아 보여 줌
  • 뱀부 계정(클라우드): 학교 PC는 프린터와 네트워크가 달라(Bambu Studio도 클라우드를 거침) 이 방식을 씀. 이메일·비밀번호 → 메일 인증 코드 → 토큰. 비밀번호는 저장하지 않고 토큰만 저장(약 3개월). 카메라는 안 됨
  • 구글로 가입한 계정은 bambulab.com에서 비밀번호를 따로 만들면 됨. Bambu Studio의 로그인 정보는 암호화돼 있어 가져오지 않음
  • 전체 화면 알림: 출력 중 → 일시정지·실패로 바뀌면 화면 전체가 주황/빨강으로 깜빡이고 원인(필라멘트 떨어짐, 노즐 막힘, 첫 레이어 이상 등)을 한국어로 표시. 완료되면 초록 알림. [확인]을 누를 때까지 유지, 다시 출력을 시작하면 저절로 닫힘. 야간 검은 화면보다 위에 뜸

ESP32 같은 작은 보드도 같은 MQTT 방식으로 상태를 받아 LCD·LED에 표시할 수 있습니다(카메라는 제외). 메이커 수업 주제로 좋습니다.

  • 10분마다 용이 지나가며 화면을 잠깐 어둡게

EXE 배포 PyInstaller onedir · GitHub Actions

main 브랜치에 올릴 때마다 GitHub Actions의 Windows 러너가 PyInstaller로 빌드해 latest 릴리스에 zip을 올립니다. 시간표 워커는 같은 exe를 --tt-worker 인자로 다시 실행하는 방식이라 파일이 하나입니다. 화면 파일이 바뀌면 WebView2 프로필 폴더를 새로 써서 예전 화면이 캐시에서 뜨지 않게 했습니다.

windowed exe에서 외부 명령(nvidia-smi)을 그냥 부르면 검은 창이 깜빡입니다. CREATE_NO_WINDOW로 호출해야 합니다.
