03투입된 기술

고정 무대 + 자동 축소 CSS transform · @container

화면 전체를 1920×440 크기의 고정된 무대(#stage) 하나로 그리고, 창 크기에 맞춰 transform: scale()로 줄이거나 늘립니다. Windows 배율(125%·150%)이나 일반 창에서도 모양이 똑같습니다. 세로 모드는 440×1920 무대로 바꿉니다. 패널 폭이 좁아지면 @container 쿼리로 글자와 항목을 줄이고, 그래도 넘치면 스크립트가 글자를 한 단계씩 줄입니다.

주의: 컨테이너 쿼리 규칙은 스타일시트 맨 끝에 둬야 기본 규칙을 덮어씁니다.

시간표: 사이트의 계산 결과만 가져오기 WebView2 · JS 주입 · 파일 캐시

시간표 사이트는 화면을 그리기 전에 브라우저 안에서 대강·시험·행사를 계산합니다. 그래서 HTML을 긁지 않고, 사이트를 실제로 열어 그 계산 엔진(TimetableEngine)을 호출하는 JS를 주입해 데이터만 받습니다. 색과 디자인은 가져오지 않습니다.

  • 같은 프로세스의 숨은 창은 WebView2에서 로드되지 않고 화면 전체가 "응답 없음"이 됐습니다. 그래서 별도 프로세스로 분리했습니다.
  • 작업표시줄에 창이 계속 떠 있는 게 불편하다는 의견에 따라, 전 주차를 한 번에 긁어 tt_cache/<교사>.json에 저장하고 창을 바로 닫게 바꿨습니다.
  • 교사별로 캐시가 따로 있어 교사를 바꿨다 돌아와도 바로 뜹니다. 교장·교감은 시간표 없이 목록에만 넣었습니다.

쿨메신저 안읽은 쪽지 SQLite 읽기 전용 · base64 + zlib + UTF-16LE

쿨메신저는 공개 API가 없지만 받은 쪽지를 %LOCALAPPDATA%\CoolMessenger\Memo\<로그인명>.udb라는 SQLite 파일에 저장합니다. 이 파일을 읽기 전용으로 열어 tbl_recv에서 IsUnRead = 1인 쪽지만 보여 줍니다. 쿨메신저가 켜져 있어도 읽힙니다.

SELECT Sender, Title, MessageText, ReceiveDate, IsUnRead
FROM tbl_recv
WHERE (DeletedDate IS NULL OR DeletedDate = '') AND IsUnRead = 1
ORDER BY ReceiveDate DESC LIMIT 20;
  • 파일 이름은 Windows 계정이 아니라 쿨메신저 로그인 이름이라 *.udb 중 가장 최근 파일을 고릅니다.
  • 컬럼 이름이 IsUnRead라서 1이 "안읽음"입니다. 처음에는 반대로 해석해 배지가 틀렸습니다.
  • HTML 본문 MessageBody는 {COMP} 뒤에 base64 → zlib → UTF-16LE로 압축돼 있지만, 평문 MessageText가 있어 그걸 씁니다.
  • DB에는 절대 쓰지 않습니다. 패널의 지우기는 화면에서만 숨깁니다.

학교 일정 웹앱 연동 Apps Script 페이지 파싱

Apps Script 웹앱은 실제 페이지를 샌드박스 iframe 속에 역슬래시-x로 이스케이프해 넣어 보냅니다. 이스케이프를 몇 번 풀어 <script id="init-data"> 안의 JSON을 꺼내면 부서 일정과 학사일정이 그대로 들어 있습니다. 10분마다 다시 받고, 설정의 새로고침을 누르면 즉시 받습니다.

날씨 연출 Canvas 2D · 맨 앞 레이어 · pointer-events: none

Open-Meteo의 날씨 코드(WMO), 낮밤, 풍속으로 연출을 고릅니다. 화면 맨 앞에 투명 캔버스를 깔고 클릭은 통과시키며, 글자를 가리지 않게 얇고 반투명하게, 큰 것은 가장자리 쪽에 둡니다.

날씨연출기법
구름·흐림안개보다 조금 진하고 작은 솜털 구름이 둥둥방사형 그라디언트 덩어리 3~4개를 겹치고 사인파로 오르내림
비부슬부슬 빗줄기 + 액정 물방울물방울 그림을 크기별로 미리 그려 두고 재사용(그림자·굴절 반짝임·반사광)
뇌우갈라지는 번개 줄기, 번쩍임무작위 꺾은선 + 그림자 번짐, 깜빡임 곡선
눈3겹 눈송이, 패널 위에 쌓이는 눈, 모서리 성에패널 위치를 읽어 높이 배열에 쌓고 이웃과 고르게 퍼뜨림
안개짙은 안개 띠크게 늘린 타원 그라디언트
맑은 낮·밤햇살 줄기 / 반짝이는 별과 별똥별회전한 선형 그라디언트 / 깜빡임 사인파
바람7m/s↑ 단풍잎, 11m/s↑ 바람 줄기뒤집히며 날리는 잎, 끝이 말리는 곡선

윤곽이 있는 그림 구름은 "안 예쁘다"는 의견으로 뺐습니다. 실제 화면 확인 → 피드백 → 수정 반복이 가장 효과적이었습니다.

화면 보호 용 Kling AI 영상 · ffmpeg 편집 · VP9 알파 webm

클링(Kling)에서 초록 배경의 황금용 영상을 만들고, ffmpeg로 편집해 배경이 투명한 webm을 프로그램에 넣었습니다.

  1. 10초 원본에서 용이 왼쪽을 보는 구간(8~10초, 0~1.1초)만 골라 이어 붙임
  2. 1.25배속, 앞으로 재생 후 거꾸로 재생해 끊김 없이 반복
  3. 초록이 다른 색보다 튀는 만큼 투명하게(크로마키), 가장자리 초록 번짐은 빨강 값으로 낮춤
  4. 화면에서는 오른쪽→왼쪽으로 물결치듯 이동, 진행 방향에 따라 머리를 들고 숙이게 기울임, 금빛 후광과 금가루 입자
ffmpeg -i kling.mp4 -an -filter_complex \
 "[0:v]trim=8:10.04,setpts=PTS-STARTPTS[a];[0:v]trim=0:1.1,setpts=PTS-STARTPTS[b];\
  [a][b]concat=n=2:v=1,setpts=PTS/1.25,scale=-2:460,format=rgba,\
  geq=r='r(X,Y)':g='min(g(X,Y),r(X,Y))':b='b(X,Y)':\
  a='255-clip((g(X,Y)-max(r(X,Y),b(X,Y))-14)*8,0,255)',format=yuva420p" \
 -c:v libvpx-vp9 -pix_fmt yuva420p -b:v 1800k dragon.webm

용 몸이 초록·청록이면 몸까지 지워집니다. 클링 프롬프트에 "용에는 초록 없음, 금·샴페인·아이보리만"을 넣는 게 핵심입니다.

번인(잔상) 대책 야간 모드 · 배경 밝기 · 움직임

  • 10분마다 용이 지나가며 화면을 잠깐 어둡게

EXE 배포 PyInstaller onedir · GitHub Actions

main 브랜치에 올릴 때마다 GitHub Actions의 Windows 러너가 PyInstaller로 빌드해 latest 릴리스에 zip을 올립니다. 시간표 워커는 같은 exe를 --tt-worker 인자로 다시 실행하는 방식이라 파일이 하나입니다. 화면 파일이 바뀌면 WebView2 프로필 폴더를 새로 써서 예전 화면이 캐시에서 뜨지 않게 했습니다.
