SUB모니터 연수 기획 회의록과 연수운영계획서

기획팀 5명, 연수운영팀 5명, 총무과 2명이 다섯 번 회의해 SUB모니터의 개선 방향과 교원 연수자료를 정하고, 연수운영계획서를 작성했습니다.

이 회의는 AI가 역할을 나눠 진행한 가상 회의입니다. 참석자는 역할 이름(기획1~5, 운영1~5, 총무1~2)으로만 적었고, 실제 인물·학교와 관계가 없습니다. 날짜·예산·인원은 실제 일정과 규정에 맞춰 고쳐 쓰세요. 연수운영팀 인원은 따로 정해 주지 않아 5명으로 두었습니다.

1차 회의 — 현황 진단과 연수 목표

참석: 기획1~5, 운영1~5, 총무1~2 (12명) · 진행: 기획1 · 기록: 운영5

안건

  1. SUB모니터가 지금 할 수 있는 것과 실제 사용에서 드러난 문제
  2. 연수 대상과 목표

논의

기획1 지금 SUB모니터는 시계·날씨·시간표·학교 일정·쿨메신저 안읽은 쪽지·PC 상태·바로가기를 한 화면에 띄웁니다. 시간표는 학교 시간표 사이트의 계산 결과를, 쪽지는 쿨메신저 PC의 로컬 DB를 읽기 전용으로 가져옵니다.

기획2 실제 사용에서 막힌 곳을 정리했습니다. ① 업데이트 zip을 풀었는데 예전 exe가 실행됨(압축 구조 문제, 해결됨) ② 저장된 설정 때문에 새 메뉴가 안 보임(해결됨) ③ 프로그램 경로가 PC마다 다름 ④ 교사 이름·일정 주소를 처음에 손으로 넣어야 함. 대부분 "설치와 첫 설정"에서 막힙니다.

운영1 연수에서 가장 걱정되는 건 PC 환경 차이입니다. 보안 프로그램, 관리자 권한, 쿨메신저 버전이 다 다릅니다. 연수 시간의 절반이 설치에 쓰이면 실패합니다.

운영2 그래서 목표를 둘로 나누자는 의견입니다. 1단계는 누구나 "설치해서 쓰기", 2단계는 원하는 사람만 "Claude와 대화로 내 화면 고치기". 처음부터 만들기는 심화로 돌립니다.

기획3 이 프로그램의 진짜 가치는 "교사가 AI와 대화로 자기 업무 도구를 만들 수 있다"는 경험입니다. 설치만 하고 끝나면 앱 하나 보급하는 것과 같습니다. 2단계를 반드시 맛보게 해야 합니다.

총무1 1920×440 서브모니터를 전원에게 사 줄 수는 없습니다. 연수용 몇 대만 준비하고, 평소에는 일반 모니터에서도 쓸 수 있어야 보급이 됩니다.

기획4 개인정보도 짚어야 합니다. 쪽지 내용이 화면에 그대로 보이니, 수업 중 화면 공유나 학생이 오가는 자리에서는 가릴 수 있어야 합니다.

결정
  • 연수 목표 2단계: ① 설치·활용(전원) ② AI와 대화로 고치기(전원 맛보기, 심화는 선택)
  • 연수 전에 프로그램을 "설치와 첫 설정이 막히지 않게" 고친다 (2차 회의 안건)
  • 서브모니터는 연수용으로 소수만 준비하고, 일반 모니터 모드를 만든다
할 일
  • 기획2: 사용 중 문제 목록을 과제 카드로 정리
  • 운영1: 교내 PC 환경 조사표(OS, 권한, 쿨메신저 버전, 보안 프로그램) 작성
  • 총무1: 서브모니터 견적, 연수 장소 확인

2차 회의 — 프로그램 개선 방향

참석: 12명 · 진행: 기획1 · 기록: 운영5

안건

  1. 개선 과제 우선순위
  2. 개인정보·보안 기준

논의

기획2 과제 카드 12장을 "연수 성공에 꼭 필요한가 / 만드는 데 드는 품"으로 나눴습니다.

운영1 환경 조사 결과: 대부분 Windows 10·11, 일부는 관리자 권한 없음, 쿨메신저는 버전에 따라 설치 폴더가 다름. 시작 메뉴 바로가기는 공통으로 있습니다.

기획5 그래서 바로가기 경로는 "알려진 경로 → 시작 메뉴 바로가기 → 레지스트리 → 폴더 검색" 순으로 찾는 지금 방식이 맞습니다. 아이콘은 프로그램에 넣어 둔 공식 이미지를 쓰고요.

기획4 쪽지는 내용을 읽기만 하고 외부로 보내지 않는다는 것을 설명서와 화면에 분명히 적어야 합니다. 그리고 "가리기" 버튼으로 쪽지 본문을 보낸 사람만 보이게 바꾸는 기능을 넣읍시다.

운영3 관리자 권한이 없어도 설치되어야 합니다. 지금처럼 압축만 풀면 되는 방식은 유지하되, 설치 명령을 한 줄로 줄이고 설정 파일은 덮어쓰지 않게 해야 합니다.

총무2 업데이트할 때마다 담당자가 전화를 받는 일이 없게, 프로그램이 새 버전이 있으면 알려 주고 버튼 하나로 받게 해 주세요.

3차 회의 — 연수 설계

참석: 12명 · 진행: 운영1 · 기록: 운영5

안건

  1. 연수 형태·시간·인원
  2. 트랙 구성
  3. 장소·장비·예산

논의

운영2 안 5개를 비교했습니다. 강의식 2시간은 만족도는 높지만 다음 날 아무도 안 씁니다. 실습 중심 3시간 + 선택 심화 2시간이 가장 현실적입니다.

운영4 수준 차이가 큽니다. 트랙을 셋으로 나눕시다. A(활용): 설치·설정·쓰기 / B(수정): Claude에게 말해 화면 하나 바꾸기 / C(제작): 나만의 패널 하나 새로 만들기.

운영3 한 반 15명 이하, 둘씩 짝을 지어야 합니다. 막힌 사람을 짝이 먼저 돕고, 그래도 안 되면 보조 강사가 갑니다. 보조 강사는 4~5명당 1명.

기획3 B트랙에서 Claude에게 처음부터 만들라고 하면 시간 안에 못 끝납니다. 완성된 프로그램의 화면 파일(web/index.html)을 주고 "이 부분을 이렇게 바꿔 줘"를 연습하는 게 성공률이 높습니다.

운영1 브라우저 데모를 먼저 쓰면 설치 없이도 B트랙 실습을 할 수 있습니다. 데모에서 고친 걸 본인 PC에 옮기는 건 숙제로.

총무1 장소는 컴퓨터실(30석)을 반으로 나눠 씁니다. 서브모니터 견적은 업체 두 곳에 요청했습니다. 연수용 4대(조별 1대)면 충분합니다. 예산 항목은 장비, 강사 수당, 교재 인쇄, 다과입니다. 금액은 규정 확인 후 넣겠습니다.

총무2 연수 시간 인정(학교 자율연수)은 연수원 등록 절차가 필요합니다. 출석은 서명부와 사후 설문 제출로 확인합니다.

기획1 Claude 계정이 없는 선생님이 많을 겁니다. 무료 계정으로 실습이 되는지 미리 확인하고, 계정 만들기는 사전 과제로 돌립시다.

결정
  • 본 연수 3시간(필수, 실습 중심) + 심화 2시간(선택, C트랙)
  • 회당 15명 이하, 짝 실습, 보조 강사 4~5명당 1명
  • 사전 과제: Claude 계정 만들기, PC 환경 체크(5분 점검표)
  • 설치 없이 브라우저 데모로도 B트랙을 할 수 있게 자료 구성
할 일
  • 운영2: 차시별 진행안, 운영4: 트랙별 미션
  • 총무1: 장소 예약, 장비 견적 비교, 예산안 / 총무2: 연수 등록·이수 처리 절차 확인
  • 기획1: 무료 계정 실습 가능 여부 확인

4차 회의 — 연수자료 검토

참석: 12명 · 진행: 운영1 · 기록: 운영5

안건

  1. 교재·미션·프롬프트 카드 검토
  2. 평가 방법

논의

운영2 교재는 6장입니다. 1장 무엇을 하는 프로그램인가(5분) → 2장 설치와 첫 설정 → 3장 화면 읽기 → 4장 AI와 대화로 고치기 → 5장 문제가 생기면 → 6장 더 해 보기. 글은 줄이고 화면 사진 위주로 갑니다.

기획3 4장의 핵심은 "좋은 요청 문장"입니다. 무엇을, 어디에, 어떻게 보이게, 하지 말 것. 이 네 칸을 채우는 프롬프트 카드를 만들었습니다.

운영4 미션은 쉬운 순서로 셋입니다. ① 글자 크기·색 바꾸기 ② 요약 칩에 D-day 추가 ③ 나만의 패널(급식, 오늘의 명언 등) 새로 만들기. ①은 누구나 10분 안에 성공해야 합니다.

기획2 문제 해결 FAQ는 실제로 겪은 문제부터 넣었습니다. 예전 화면이 뜰 때, 메뉴가 안 보일 때, 시간표가 비어 있을 때, 쪽지가 0건일 때, 바로가기가 안 열릴 때.

기획4 교재와 화면 사진에 실명·학교명이 나오면 안 됩니다. 모든 사진은 가상 데이터(홍길동, 우리 동네, 가상 일정)로 다시 찍었습니다.

운영3 평가는 시험이 아니라 "성공 여부"입니다. 사전 설문(경험·기대), 현장 체크(미션 성공 개수), 사후 설문(만족도, 2주 뒤 계속 쓰는지)으로 봅시다.

총무1 교재는 컬러 인쇄 대신 화면(QR 링크)으로 보고, 프롬프트 카드와 점검표만 인쇄하면 비용이 크게 줄어듭니다.

결정
  • 교재 6장(웹 페이지 + PDF), 실습 미션 3개, 프롬프트 카드 12장, FAQ, 사전·사후 설문 확정 → 붙임 참고
  • 모든 자료의 사진·예시는 가상 데이터만 사용
  • 인쇄물은 프롬프트 카드·점검표만, 나머지는 QR로 제공
할 일
  • 운영2·4: 교재·미션 최종본 / 기획3: 프롬프트 카드 / 기획2: FAQ
  • 운영3: 설문지(구글 폼) / 총무1: 인쇄 의뢰
  • 운영1: 내부 리허설 일정 잡기

5차 회의 — 리허설 점검과 최종안

참석: 12명 · 진행: 기획1 · 기록: 운영5

안건

  1. 내부 리허설 계획·점검표
  2. 연수운영계획서 최종 승인
  3. 역할 분담

논의

운영1 리허설은 팀원 중 프로그램을 처음 보는 사람 4명을 학습자로 두고 실제 시간대로 3시간 진행합니다. 시간 초과 구간, 막힌 지점, 질문을 기록합니다.

운영4 미리 예상되는 위험은 세 가지입니다. ① 설치에서 15분 이상 지연 ② Claude 응답을 그대로 붙였다가 화면이 깨짐 ③ 학교 네트워크에서 외부 사이트가 막힘. 대비책을 정해 둬야 합니다.

기획5 ①은 연수 전날 연수용 PC에 미리 설치해 두고, 개인 PC 설치는 연수 끝 30분에 짝과 함께. ②는 "고치기 전에 원본 복사해 두기"를 미션 첫 단계에 넣고, 되돌리기 방법을 카드에 적습니다.

총무2 ③은 전산 담당에게 claude.ai, github.com, 날씨 서버 주소의 접속 허용을 미리 요청하겠습니다. 안 되면 휴대폰 핫스팟 2대를 준비합니다.

운영3 연수 직후 2주간 "질문 게시판"을 열고, 2주 뒤 사후 설문을 보냅니다. 잘 고친 화면은 공유 갤러리에 올려 다음 기수 예시로 씁니다.

기획1 계획서를 함께 읽고 승인합니다. 수정 의견: 심화 과정은 신청자가 6명 미만이면 다음 학기로 미룬다는 조건을 넣읍시다.

연수운영계획서

2026학년도 「AI와 함께 만드는 내 업무 화면」 교원 연수 운영 계획

— SUB모니터 활용과 수정 실습 중심 —

Ⅰ. 목적

  • 교사가 시간표·학교 일정·쪽지·날씨를 한 화면에서 확인해 업무 확인 시간을 줄인다.
  • AI(Claude)와 대화로 자기 업무 도구를 직접 고쳐 보는 경험을 통해 디지털 업무 역량을 기른다.
  • 교사가 만든 도구를 서로 나누는 학교 문화를 만든다.

Ⅱ. 방침

  • 강의는 짧게, 실습은 길게. 모든 차시는 "직접 해 보고 성공하는 것"을 목표로 한다.
  • 수준별 3트랙(A 활용, B 수정, C 제작)으로 운영하고, 짝 실습과 보조 강사로 막힘을 줄인다.
  • 개인정보 보호: 읽기 전용·외부 전송 없음·개인 설정은 본인 PC에만 저장. 연수 자료의 예시는 모두 가상 데이터로 한다.
  • 연수 뒤 2주간 질문 게시판과 공유 갤러리로 현장 적용을 돕는다.

1. 교재 목차 (6장)

  1. SUB모니터는 무엇을 하나 — 화면 한 장으로 보는 시계·날씨·시간표·일정·쪽지·PC·바로가기. 하지 않는 것: 쪽지 보내기, 외부 전송, 내 정보 서버 저장
  2. 설치와 첫 설정 — 한 줄 설치 명령, 설정 마법사 4단계, 자동 실행 켜기

  4. AI와 대화로 고치기 — 원본 복사 → 요청 문장 4칸 → 결과 붙이기 → 확인 → 안 되면 되돌리기
  5. 문제가 생기면 — FAQ, 문제 신고 버튼, 질문 게시판
  6. 더 해 보기 — 나만의 패널, 다른 업무 도구로 넓히기, 공유 갤러리

더 좋은 아이디어

회의 안건 밖에서 나온 제안입니다. 연수보다 효과가 클 수 있어 따로 적습니다.

1. "만들기"보다 "고치기" 연수완성품을 주고 내 업무에 맞게 한 군데 고치는 미션형 연수가 성공률이 가장 높습니다. 처음 만들기는 다음 단계로.
2. 학교 공용 설정 한 장교무부가 학교 일정 웹앱·시간표 주소를 담은 설정 파일 하나만 배포하면, 교사는 이름만 고르면 끝. 설치 문의가 크게 줄어듭니다.
3. 교실용 SUB모니터같은 화면을 교실 TV·전자칠판용으로: 오늘 시간표, 급식, 다음 수업 준비물, 시험 D-day. 학생용이라 쪽지는 빼고.
4. 일반 모니터 띠 모드서브모니터가 없어도 큰 모니터 아래 80px 띠로 띄우면 장비 예산 없이 전원 보급 가능.
5. 동료 멘토제1기 수료자 중 미션 ③ 성공자를 다음 기수 보조 강사로. 같은 학교 선생님이 옆에서 도와주는 게 가장 빠릅니다.
6. 공유 갤러리교사가 고친 화면과 사용한 요청 문장을 함께 모아 두는 페이지. 다음 기수는 "남이 한 요청"을 복사해 시작.
7. 짧은 영상 교재설치·설정·미션 ①을 각 2분 영상으로. 연수 당일 결석자나 신규 교사도 혼자 따라 할 수 있습니다.
8. 업무 도구로 넓히기같은 방식(AI와 대화로 작은 도구 만들기)을 출결 확인, 수행평가 체크, 학급 공지 등으로 넓히는 후속 연수 시리즈.
