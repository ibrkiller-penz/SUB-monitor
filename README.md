# LESOWN 11.3" 가로 스트립 대시보드 (1920×440)

시계 · 날씨(부산 동래구) · 동래교사시간 시간표 · 구글 캘린더 일정 · PC 상태를 한 화면에 표시합니다.
배경은 달마다 바뀝니다 (`web/bg/01.jpg` ~ `12.jpg`, 1920×440). 원하는 사진으로 교체해도 됩니다.

## 화면 구성
- **허브**: 시계 · 날씨 · 시간표 · 일정 · PC 상태 5개 패널.
- **상세**: 패널을 터치(클릭)하면 전체화면 상세로 전환됩니다. `← 허브로` 버튼, `Esc`, 또는 90초 무조작 시 허브로 돌아옵니다.
  - 오늘: 큰 시계 + 하루 타임라인(교시·일정·현재 위치)
  - 날씨: 24시간 온도/강수확률 그래프, 7일 예보, 미세먼지 수치
  - 시간표: 주간 전체 시간표 + 이번 주 공강지도/급식지도
  - 일정: 월 달력(날짜 터치 → 해당 일 일정) + 이후 일정 + **일정 직접 추가**(이 PC에 저장, `~/.lesown_dashboard/local_events.json`, ✎ 표시, ✕로 삭제)
  - PC: CPU/RAM/GPU/네트워크 그래프, 상위 프로세스
- **메시지(쿨메신저)**: Windows 알림 또는 창 제목에서 안읽은 메시지를 감지해 표시합니다(공식 API 없음). 처음엔 `tools\coolmsg_probe.py`를 실행해 이 PC에서 어떤 방식이 되는지 확인하세요. Windows 설정 → 개인 정보 및 보안 → 알림 → "앱이 알림에 접근" 허용 필요.
- **학교일정**: `config.json > school_schedule_url`(동래고 일정 웹앱)에서 부서 일정·학사일정을 30분마다 동기화. 별도 패널로 켤 수 있고, 켜면 일정 패널에는 개인·학사 일정만 남습니다.
- **표시 항목·방향 선택**: 화면 우하단 ⚙ → 가로/세로 방향, 패널(날씨/시간표/일정/학교일정/쿨메시지/PC, **시계 제외 최대 4개**), 시계 아래 요약 항목(최대 4개). 우하단 ✕ 로 종료.
- **주차 이동**: 시간표 패널·주간 상세의 ◀ ▶ 로 다른 주차 확인, `오늘` 버튼으로 복귀(3분 뒤 자동 복귀).
- **설정(⚙)**: 시간표 패널 오른쪽 톱니 → 교사 변경, 시간표 새로고침.

## 설치 / 실행 (Windows)
1. Python 3.10+ 설치 (설치 시 **Add python.exe to PATH** 체크)
2. 디스플레이를 연결하고 Windows 설정 → 디스플레이에서 **방향: 가로**, 해상도 1920×440으로 맞춥니다.
3. `run.bat` 더블클릭 → 처음 실행할 때 라이브러리를 자동으로 설치하고, LESOWN 화면을 찾아 전체화면으로 띄웁니다. 보조모니터가 없으면 일반 창으로 뜹니다.
   - 종료: 우하단 ✕ 또는 `Esc`
   - 시간표는 사이트를 잠깐(몇 초) 최소화 창으로 열어 전 주차를 긁은 뒤 `%USERPROFILE%\.lesown_dashboard\tt_cache\<이름>.json`에 저장하고 창을 닫습니다. 30분마다(`config.json > timetable_refresh_min`), 날짜가 바뀔 때, 교사를 바꿀 때, 설정 > 새로고침 때 다시 긁습니다. 교사별 캐시가 남아 있어 교사를 바꿨다 돌아와도 바로 뜹니다.
   - 문제가 생기면 `%USERPROFILE%\.lesown_dashboard\app.log`, `tt_worker.log` 를 보내주세요.

## 설정
개인 설정(교사 이름, 표시 패널, 캘린더 주소 등)은 화면에서 바꾸면 `config.local.json`에 저장됩니다(저장소에 올라가지 않음). 처음 실행하면 ⚙에서 자기 이름을 고르면 됩니다. 아래는 공용 기본값 `config.json` 설명입니다.
- **구글 캘린더**: 구글 캘린더 웹 → 설정 → 내 캘린더 → *캘린더 통합* → **비공개 주소(iCal 형식)** 를 복사해서
  `"ical_urls": ["여기에 붙여넣기"]` 에 넣습니다. 여러 개를 넣을 수 있습니다.
- **시간표**: 처음 실행 시 시간표 칸에서 선생님을 고르면 `teacher_name` 에 저장됩니다.
  시간표는 사이트를 잠깐 열어 계산된 데이터(대강·변경·시험 반영)만 가져와 로컬에 저장해 두고 표시합니다.
- **날씨 지역**: `latitude` / `longitude` 값을 바꾸면 됩니다.

## 자동 실행 (Windows 시작 시)
`Win + R` → `shell:startup` → 열린 폴더에 `run.bat` **바로가기**를 넣습니다.

## exe 버전 (Python 설치 불필요)
- GitHub에 올라갈 때마다 자동으로 Windows exe가 만들어집니다: **Releases → `latest` → `LesownDashboard-win.zip`** 다운로드 → 압축 해제 → `LesownDashboard.exe` 실행.
  (https://github.com/ibrkiller-penz/SUB-monitor/releases/latest)
- 직접 만들려면 `build_exe.bat` 실행 → `dist\LesownDashboard\` 폴더가 생깁니다. 폴더째 복사해서 쓰세요.
- **작업표시줄에 고정**: 압축 푼 폴더의 `LesownDashboard.exe` 우클릭 → (Windows 11은 "더 많은 옵션 표시") → **작업 표시줄에 고정**. 실행 중일 때는 작업표시줄 아이콘 우클릭 → 고정.
- Windows SmartScreen 경고가 뜨면 "추가 정보 → 실행". 처음 실행 시 ⚙에서 이름을 고르면 `config.local.json`이 exe 옆에 생깁니다.

## 참고
- GPU 사용률/온도는 NVIDIA 그래픽카드만 표시됩니다. CPU 온도는 Windows 제약으로 표시하지 않습니다.
- 교시 안내(시계 아래)의 종료 시각은 수업 50분으로 가정했습니다. 다르면 `web/index.html`의 `PERIODS` 를 수정하세요.
- 날씨: Open-Meteo (무료, API 키 불필요)
